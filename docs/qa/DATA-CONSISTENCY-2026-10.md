## Limitations

- The QA fixture in defect 4 (a Boise event in an India cinema room) is a data error still on QA; an
  owner should repair or remove it. This branch only stops the consoles disagreeing about it.
- Defect 5: a visitor with a country chosen and nothing on sale there now sees an empty film page.
- Defect 6 does not stop approving a past event; it makes it visible.
- Full API jest: 25 integration-postgres suites failed under load on the shared local database
  (counts moving under other engineers' writes; admin-grouping also failed alone with drifting counts).
  None touch files changed here. All unit suites pass.
