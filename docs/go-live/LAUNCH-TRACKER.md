# Launch tracker: platform capabilities, then every open item until it is closed

One list. An item leaves it only when it is **closed with evidence**, **deferred by the owner**,
or **confirmed not applicable**. Nothing is dropped because something newer came up. The
architecture register (`docs/architecture/PRODUCTION-READINESS-REGISTER.md`, `AR-nn`) keeps the
engineering detail; this file is the decision view.

**How to read it (owner direction, 2026-11-10).** ETicketsGo is judged as a multi-organizer platform
for independent organizers in India and the USA. A capability is GO when it works for any properly
set-up organizer. Problems in one account's data (the founder test organizations DeepTrics India,
DeepTrics Idaho, DeepTrics LLC, ETicketsGo Presents) are listed separately under
**Account-specific data** and never make the platform NO-GO by themselves.

Last updated: 2026-11-10. PROD: api, organizer-web, admin-web at 175282bf (migration 158); worker
c6c84db4; customer-web a823a0f0.

Type: **CODE** defect, **CONFIG**uration, **OWNER** decision, **HARDWARE** verification,
**DEFERRED** by the owner.
