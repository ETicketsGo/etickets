# India pilot end-to-end journey

Prepared 2026-10-12 from `origin/main e3e289e`. One organizer, one GA event, one buyer, one ticket, from
onboarding to payout. Each step names the actor, the console path, and the **system evidence** that proves
the step happened. "Audit" means the Admin console Audit log (`/admin/audit`, needs `BOOKING_READ`) filtered
by the action name. Detailed procedures are in `docs/pilot/OPERATING-PROCEDURES.md` (referred to as OP).

No live environment was queried. Steps that depend on live configuration say **VERIFY LIVE**.

## Money trail for one example ticket

Use these checks at step 21 to prove the figures agree. Amounts are per currency and never combined.

1. Ticket face value in the event's tickets list equals the booking line.
2. Booking total equals ticket value plus fees plus GST on fees (shown on the receipt).
3. Payment amount in Admin Payments equals the booking total.
4. The refund (if any) equals ticket value plus tax added on top, not fees.
5. Payout net equals sold ticket value less refunds, per the organizer's terms and the fee handling the
   event chose.
6. Payout PAID amount equals the bank transfer amount.
