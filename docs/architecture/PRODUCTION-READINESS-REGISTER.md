## Rules for adding findings

- Verify against the repository and, read-only, against the running environments before
  writing a row. Record what was checked in "Current state".
- One PR per finding (or a small, coherent group). Do not widen a PR that is already in
  review; add a row instead.
- Anything needing production access, credentials, money, a subscription or a business
  decision is `blocked (owner)` with the exact ask in "Fix".
