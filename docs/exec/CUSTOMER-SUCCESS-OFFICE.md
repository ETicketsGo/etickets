# VP Customer Success — Success Office

Operating model for onboarding, retention, renewals, health, community, and
advocacy. Extends the [Organizer Success Playbook](../gtm/ORGANIZER-SUCCESS-PLAYBOOK.md)
and [Support Playbook](../gtm/SUPPORT-PLAYBOOK.md); this doc is the CS org's charter.

## Charter & principles

- **CS owns net revenue retention (NRR)** and the **health score**.
- **Time-to-value first:** the fastest path to "published + first sale + first
  payout" beats every other activity.
- **Proactive, not reactive:** health-triggered plays before tickets are filed.
- **Segment the touch:** self-serve automation for the long tail, named CSM for
  managed/strategic.

## Customer lifecycle (organizer)

```
Onboard → Activate → Adopt → Value → Expand → Renew/Advocate
  ↘ (any stage) At-risk → Save
```

| Stage              | Definition                                     | CS goal            | Primary play                                 |
| ------------------ | ---------------------------------------------- | ------------------ | -------------------------------------------- |
| **Onboard**        | Signup → first publish                         | <15 min publish    | template + guided setup + concierge if stuck |
| **Activate**       | First sale + first payout                      | prove money works  | payout explainer; celebrate first sale       |
| **Adopt**          | ≥ 2 experiences / reminders on / staff trained | build habit        | duplicate/recurring nudges; check-in dry-run |
| **Value**          | GMV growing; low support                       | realize ROI        | analytics review; best-practice tips         |
| **Expand**         | Pro/white-label/add-ons/more currencies        | grow NRR           | upsell play (see below)                      |
| **Renew/Advocate** | Renewal + referral/case study                  | lock-in + flywheel | QBR; referral + case-study ask               |
| **At-risk**        | Health 🔴 / dormant / failures                 | reverse decline    | save plays                                   |

## Onboarding (two tracks)

### Organizer onboarding

- Self-serve: use-case picker → template → publish → promotion kit → "connect
  payments" guided task. Lifecycle emails nudge each milestone.
- Managed: 30-min kickoff using the [onboarding checklist](../gtm/ORGANIZER-SUCCESS-PLAYBOOK.md#onboarding-checklist-give-to-every-new-organizer);
  event-day readiness confirmed.
- **Target:** <15-min first publish; 7-day activation ≥ 60%.

### Customer (attendee) onboarding

- Frictionless discover → buy → instant QR + multi-channel confirmation → reminders.
- CS supports organizers in configuring reminders/waitlists to cut no-shows.

## Training

- **Video library** (10 videos, per [Support Playbook](../gtm/SUPPORT-PLAYBOOK.md#video-plan-production-order)).
- **Quick-start guides** per persona; **webinars** ("publish in 15 min",
  "event-day operations", "reading your analytics").
- **Certification (light):** "ETicketsGo Organizer" badge for power users / agencies.

## Support (summary — full model in Support Playbook)

Channels (in-app, email, WhatsApp, community), tiers L1→L3→Incident, KB-first
deflection. CS + Support share the health signal.

## Retention & renewals

- **Retention levers:** duplicate/recurring, seasonal templates, reminders/waitlists,
  fast payouts, analytics value. Repeat organizers are the LTV engine.
- **Renewals (subs):** 90/60/30-day renewal motion for Pro/Business; value recap +
  usage proof + QBR; auto-renew with transparent notice.
- **Churn early-warning:** health 🔴, no publish 30d, payment-failure spike, CSAT drop.

## Health scoring

Use the [0–100 health score](../gtm/ORGANIZER-SUCCESS-PLAYBOOK.md#customer-health-score-0100)
(activation, recency, frequency, GMV trend, payment success, refund rate, support
sentiment, payout success). Recompute weekly; auto-trigger plays on band change.

## Escalation matrix

| Trigger                          | Owner                       | Action                            | SLA                                                             |
| -------------------------------- | --------------------------- | --------------------------------- | --------------------------------------------------------------- |
| Health 🔴 (band drop)            | CSM                         | outreach + save play              | 48h                                                             |
| No publish 30d                   | CS auto → CSM               | template + 15-min call offer      | 3d                                                              |
| Payment-failure spike            | CS → Ops                    | provider check + comms            | same day                                                        |
| Sev-1 (event-day money/check-in) | Support → Ops on-call → Eng | incident bridge; organizer comms  | immediate (see [runbook](../guides/PROVIDER-OUTAGE-RUNBOOK.md)) |
| Payout delay/dispute             | CS → Finance                | trace settlement + reconciliation | same day                                                        |
| Renewal at risk                  | CSM → CRO                   | value recap + exec sponsor        | 14d pre-renewal                                                 |
| Detractor NPS                    | CSM                         | root-cause interview + fix loop   | 48h                                                             |

## Community

- **Organizer community** (forum/WhatsApp/Slack): peer help, templates, feature
  voting, event-day tips. Deflects support + fuels advocacy.
- **Ambassador program** (campus + power organizers): referrals + local evangelism.
- **Roadmap voting** board: transparency → trust.

## Customer advocacy

- **Reference program:** every 🟢 high-GMV organizer → case study + 2 referrals.
- **Advocacy ladder:** happy user → reviewer → case study → speaker/logo → ambassador.
- Incentivize with fee credits, early access, co-marketing, and recognition.

## Quarterly success plan (Q1)

- **Objective:** prove activation + retention foundations in the pilot.
- **KRs:** <15-min publish (median); 7-day activation ≥ 60%; ≥ 6/10 pilots retained;
  NPS ≥ 40; CSAT ≥ 4.3; ≥ 3 case studies + ≥ 5 referrals; health score live +
  weekly plays running.
- **Motions:** CSM per pilot; weekly check-ins + digest; you-asked-we-shipped;
  event-day on-call; end-of-pilot interviews → advocacy.

## CS KPIs

NPS, renewal rate, expansion revenue, tickets/100 orgs, advocacy (case studies +
referrals). Targets in [Success Metrics](../gtm/SUCCESS-METRICS-KPIS.md).
