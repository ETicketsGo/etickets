## The through-line

- **Mission:** the Experience Commerce Platform — sell, run, and monetize live
  experiences (movies + events + adjacent) across markets.
- **Status:** product complete + production-grade; **pre-revenue, pre-pilot**. The
  gating work is commercial execution, not engineering.
- **This quarter:** run the 10-organizer pilot, produce reference case studies, reach
  self-serve GA in the beachhead (India + one English market) — holding money-
  integrity and reliability guardrails.
- **Discipline (every function):** no speculative features; no growth that breaks
  payment success / refunds / reliability; measure everything; AI only where ROI is
  measurable and never autonomously deciding on money.
