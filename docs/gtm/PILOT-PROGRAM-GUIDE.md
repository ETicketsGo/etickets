# Pilot Program Guide

Covers **Phase 4**. Structured pilot to prove value, generate references, and
harden operations before GA.

## Goals & scale

- **10 organizers**, **100 experiences**, **5,000 attendees** over **6–8 weeks**.
- Secondary: 3–5 publishable **case studies**, validated **onboarding <15 min**,
  a clean **payment-live** track record, and a prioritized fix list.

## Cohort selection (who to recruit)

Diversify across the beachhead so results generalize:

| Slot | Segment                   | Market     | Why                                  |
| ---- | ------------------------- | ---------- | ------------------------------------ |
| 1–2  | College fest / university | India / UK | high volume, references, ambassadors |
| 3    | Event company (agency)    | India      | multi-event, highest-LTV, power user |
| 4    | Conference organizer      | UK/AU      | tiers/tracks stress test             |
| 5    | Music promoter            | India/UK   | on-sale reliability + scale          |
| 6    | Comedy (recurring)        | any        | repeat/no-show automation            |
| 7    | Sports club (season)      | AU/India   | seasons + gates + members            |
| 8    | Regional cinema           | India      | movies + seat maps + payouts         |
| 9    | Nonprofit fundraiser      | AU/UK      | fees + receipts + goodwill           |
| 10   | Startup community         | any        | free→paid, waitlists, sponsors       |

**Recruit via:** founder network, campus ambassadors, partner intros (Razorpay/
Stripe/Square, universities), and warm outbound to the ICP. Offer "**Founding
Organizer**" perks: reduced/waived platform fee during pilot, white-glove setup,
logo on the site, roadmap input.

## Success criteria (go/no-go to GA)

**Must-hit:**

- Median **time-to-first-publish < 15 min**; ≥ 80% of pilots publish unaided.
- **Payment success ≥ 97%**; **0 Sev-1** money/check-in incidents unresolved.
- **≥ 100 experiences** and **≥ 5,000 attendees** processed.
- **Payouts 100% on-time**; reconciliation queue drained each week.
- **Organizer CSAT ≥ 4.3 / NPS ≥ 40**; **≥ 6/10 organizers commit to keep using**.
- **≥ 3 case studies** with quantified results + **≥ 5 referrals**.

**Nice-to-have:** ≥ 40% run a second experience; ≥ 1 white-label/Pro upgrade intent.

## Support process (high-touch)

- Each pilot gets a named **CSM** + a shared channel (WhatsApp/Slack/email).
- **Onboarding call** (30 min) using the [onboarding checklist](./ORGANIZER-SUCCESS-PLAYBOOK.md#onboarding-checklist-give-to-every-new-organizer).
- **Event-day on-call:** for every scheduled large event, an owner is pre-assigned,
  [launch-gate/readiness](../guides/PRODUCTION-ACTIVATION.md) confirmed, and payment
  - check-in metrics watched live with a rollback path.
- SLAs per the [Support Playbook](./SUPPORT-PLAYBOOK.md) (event-day = immediate).

## Weekly reviews (operating rhythm)

- **Internal Monday standup:** metrics vs targets (activation, GMV, payment success,
  refunds, tickets, health scores), incident review, action list.
- **Per-organizer weekly check-in (15 min):** what shipped/sold, blockers, upcoming
  events, feedback captured.
- **Friday cohort digest:** wins, at-risk (🔴 health), fixes shipped, next-week plan.
- Track **actions-closed rate** as a pilot KPI.

## Feedback process

- In-app feedback + weekly check-ins + a shared board feed a single **pilot backlog**
  (bug / friction / feature), triaged by severity + segment impact.
- **You-asked-we-shipped** loop: notify the organizer on every fix; publish weekly
  release notes to the cohort.
- End-of-pilot **interview** (30 min) per organizer → persona/journey validation +
  case study material.

## Incident handling

- Severity + escalation per the [Support Playbook](./SUPPORT-PLAYBOOK.md#issue-escalation--slas)
  and the [Provider Outage Runbook](../guides/PROVIDER-OUTAGE-RUNBOOK.md).
- **Event-day Sev-1** (payments/check-in): immediate bridge, failover/maintenance
  controls, comms to the organizer, post-incident review within 24h.
- Every incident → root cause → fix or documented mitigation → shared learning.
- Money integrity first: reconciliation queue reviewed after any payment incident;
  never auto-correct financial records.

## Pilot → GA gate (exit review)

Hold a **go/no-go** at week 6–8:

- Success criteria met? Guardrails healthy? Case studies + references in hand?
- Top friction fixed or scheduled? Onboarding <15 min proven?
- **If GO:** flip on self-serve in beachhead markets, publish case studies, launch
  the campaign (see [Marketing Playbook](./MARKETING-PLAYBOOK.md) + [90-Day Plan](./90-DAY-LAUNCH-PLAN.md)).
- **If not:** extend 2–4 weeks, fix the top blockers, re-review.

## Pilot toolkit (checklist)

- [ ] 10 organizers signed to a lightweight Founding-Organizer agreement
- [ ] CSM + channel per organizer; onboarding calls booked
- [ ] Metrics dashboard live (activation, GMV, payment success, refunds, CSAT)
- [ ] Event-day on-call rota + readiness checks
- [ ] Pilot backlog + weekly review calendar
- [ ] Case-study + interview templates ready
- [ ] Exit go/no-go scheduled
