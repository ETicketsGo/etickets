# QA demo image sources

Every picture the QA demo seed uploads, where it came from and under what licence. The seed
(`seed-qa-demo.mjs`) downloads each one from its download URL and refuses it if the bytes no
longer match the recorded sha256, so this list always describes exactly what is on QA.

- **Licence:** all 22 images are [CC0 1.0](https://creativecommons.org/publicdomain/zero/1.0/)
  (public domain dedication): commercial use allowed, no attribution required. Authors are still
  credited here and in each demo event's description.
- **Found through:** [Openverse](https://openverse.org) with the licence filter set to CC0; each
  row links the Openverse record as a second witness to the licence. StockSnap states that every
  image on the site is CC0 (https://stocksnap.io/license); Wikimedia Commons files were checked
  for `LicenseShortName: CC0` through the Commons API.
- **Downloaded:** 2026-10-10.
- **Not used:** real film posters, logos, brand names or photos of named people. Film posters
  are abstract or landscape photographs for fictional titles.
- **Binaries are not committed.** Sizes run from 22 KB to 1.7 MB; the script fetches them.
